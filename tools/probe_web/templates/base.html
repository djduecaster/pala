Probe Help: Inputs and Outputs

Env Processor (pala.env_summary.v1)

Primary inputs: 4 ordered images, system prompt, env contract, policy identity, context JSON, timeout, model/provider/base URL, sampling/token knobs.

Derived packet fields: frame timeline from inter_frame_ms, multimodal messages (images + user text), response_format JSON schema.

Expected output JSON keys: schema_version, scene, events, hypotheses, summary_short, delta_score, features.

Features keys: person_present, zone_hint, activity_level, novelty.

Intent Proposer / Planner (pala.intent_proposals.v2)

Primary inputs: env parsed output (unless disabled), planner context, policy identity/capabilities/safety/style, planner prompt, planner image selection, planner system prompt, response_format JSON schema.

Adjustable planner packet controls: image indices, context override JSON, user-text override, full payload override JSON.

Expected output JSON keys: schema_version, proposals (optional notes_short).

Per-proposal required keys: intent, primitive, command, style, score, confidence, urgency, risk, allow_interrupt, rationale_short, evidence.

Run Modes

Run Env, Preview Planner Inputs: runs env only, shows full planner request packet that would be sent.

Run Planner From Prepared Env: uses a prepared env run ID and executes planner with current planner controls.

Run Env + Planner: single-pass chain in one request cycle.

Where to inspect full packets

Use Effective Inputs sections and Request Payload (Redacted) blocks for full env/planner packets including schema, context, prompts, messages, and selected images.
