PALA Probe Web V4

Single-call behavior decision probe + deterministic mode FSM simulator

Probe Help: Inputs and Outputs

Behavior V4 Model Packet

Primary inputs: 4 ordered images, policy identity/capabilities/safety/style, planner prompt, system prompt, model target, and request knobs.

Context source: the mode FSM simulator state (mode, active_skill, mode contracts, current action, timing, signals).

Model output schema: pala.behavior_decision.v1 with keys schema_version, mode, mood, skill, action, confidence, rationale_short, mode_transition.

Action validation: ActionGuard enforces allowed skill/primitive, dwell, cooldown, and staleness before committing.

Override Fields

Context Override JSON: replace the auto context packet.

User Text Override: bypasses build_behavior_v4_user_text.

Payload Override JSON: full request replacement (model/messages/response_format/etc.).

Mode FSM Simulator

Step signals: person_present, person_conf, search_requested, search_complete, task_active, startup_complete, health_degraded.

Force mode: optional hard transition for scenario testing.

State outputs: current mode, active skill, current action, action age, last transition, last guard result.

Run Output Sections

Packet View: compact + expanded field summaries of what was sent.

Request Payload (Redacted): complete outbound payload with image URLs redacted.

Parsed Decision / Raw Content: parser and transport diagnostics.

Guard Result / Final Action: accepted/rejected reason and committed action.

Effective Inputs: full target, knobs, policy, context, schema, messages, payload, and FSM snapshots.
