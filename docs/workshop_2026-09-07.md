## Design lessons and remaining checks

- User reports pitch3's mechanical design is weak; avoid emphasizing pitch3
  motion in this version of the gestures.
- On this body, small yaw/roll movements were inadequate. Larger coordinated
  arm movement plus shade orientation improved the operator's assessment.
- Greater amplitude is not a universal rule for every emotion. Settling will
  compare return timing using the already selected attention pose.
- The preferred attention candidate has one 5/5 run. Three repeat trials and
  direct-front video review remain to establish repeatability and that viewpoint.
- Next comparison: same approach/attention, then return at 6 degrees/s and hold
  zero for 3 s. This settling variation is not yet accepted or rated here.
